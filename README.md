### Inventory & Sales risk dashboard
Excel-based retail analytics dashboard analyzing SKU inventory, sales-at-risk, stockout risk, and category performance for CPG account support.
**Description:**  
Built an Excel-based retail account analytics dashboard to evaluate SKU-level inventory availability, projected stockout risk, and sales-at-risk across a CPG portfolio. The project converts raw sales, demand, inventory, and replenishment data into an executive-ready view for account reviews and commercial action planning.

**Key skills used:**  
Excel, Power Pivot, Retail Analytics, Inventory Analysis, Sales-at-Risk Modeling
